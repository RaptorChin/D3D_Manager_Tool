## 0. 目標與範圍

模擬跑完後，不必開 Delta Shell 或 GIS 就能快速看懂「淹多深、淹多大、抽水站有沒有正常運作、跟其他情境比如何」。

- **與 run SPEC P4 的分工**：P4「結果檢核」回答「這次模擬是否有效」（R01～R06，產出 `run_report`）；
  本模組回答「結果是什麼」，並以檢核通過的輸出為輸入。
- 全部**唯讀** `output\`（及批次產生的 `output_<事件名>\`），不得修改或刪除使用者的輸出資料。
- 核心程式放 `core/results/`，不得 import UI 套件；圖表以檔案（PNG）或資料陣列回傳，由 UI 呈現。
- UI 位置：「③ 檢視成果」工作區（`docs/UI_PLAN.md` §1.3）。共用資訊列＝成果資料夾＋總判定徽章；
  分頁＝結果檢核（run SPEC P4）、淹水統計（V1）、時序圖（V2）、情境比較（V3）；V4 報告放在淹水統計分頁的「匯出」區或另開分頁（待決事項 D8）。

## 1. 輸入資料

| 檔案 | 內容 | 備註 |
|---|---|---|
| `<mdu>_000N_fou.nc` | 各子域 wd / wl 最大值 | 平行計算每個 rank 一份，需合併或逐份讀取 |
| `<mdu>_merged_map.nc` 或 `_000N_map.nc` | 各時間步 2D 結果 | P4 R06 以 `dfmoutput mapmerge` 合併 |
| `<mdu>_0000_his.nc` | 測站、結構物時序 | 平行時只由 rank 0 輸出，含全部測站 |
| `run_report.json` | P4 檢核結果、判定 | 顯示在成果頁頂端，無效模擬要醒目標示 |

變數名稱以實機 his/map 為準（P4 會產生 `fixtures/runs/his_header.txt`）。

## 2. 候選功能

### V1 淹水成果統計與匯出
- 最大淹水深度（fou wd max）分級面積統計，級距可設定（預設 0.3 / 0.5 / 1.0 / 2.0 m）。
- 最大淹水深度圖預覽（靜態圖即可）。
- 匯出：網格面（face）中心點 CSV（x、y、最大水深），以及 GIS 可用格式（GeoTIFF／ASCII grid，
  座標系統 TWD97 EPSG:3826）。需評估新增套件（如 rasterio 或自行寫 ASCII grid）的打包成本。

### V2 時序圖
- 選測站：水位、水深、雨量（mm/day ÷ 24 換算成時雨量）。
- 選抽水站：抽水量對照 capacity（標示分割邊界抽水站，承接 P4 R02）。
- 匯出 PNG 與 CSV。

### V3 多情境比較
- 讀多個 `output_<事件名>\`（P5 批次佇列產物）：彙總表（判定、執行時間、各級淹水面積、最大水深）。
- 兩情境最大淹水深度差異（同網格才可比，需檢查網格一致）。

### V4 成果報告
- 整合 run_report ＋ V1 統計 ＋ 指定時序圖，輸出 zh-TW 報告（txt／xlsx，格式待確認）。

## 3. 效能與限制

- map.nc 可能數十 GB：只讀需要的變數與時間步；V1 優先使用 fou.nc，避免整批讀 map。
- NcFormat = 4 時，計算中無法讀取（HDF5 檔案鎖）；成果頁只在計算結束後開放。
